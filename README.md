# Image Tools

Eine Website zur Bildbearbeitung direkt im Browser.

## Funktionen

- Bildgröße ändern und Seitenverhältnis beibehalten.
- Bilder in PNG, JPEG und WebP konvertieren.
- Qualität für JPEG und WebP einstellen.
- Ergebnis anzeigen und herunterladen.
- Oberfläche auf Deutsch, Ukrainisch und Englisch.

Die Bilder werden lokal auf dem Gerät verarbeitet
und nicht auf einen Server hochgeladen.

## Technologien

HTML, SCSS, JavaScript und Canvas API.
